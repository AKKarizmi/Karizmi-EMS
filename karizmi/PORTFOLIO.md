# Portfolio and LinkedIn presentation

## Short project description

Karizmi EMS is a native C++20/Win32 examination-monitoring development preview that customizes UltraVNC capture and viewer engines for offline IPv4 LAN classrooms. Separate Teacher and Student applications combine device discovery, authenticated pairing, Botan TLS 1.3 transport, and a multi-session dashboard supporting up to ten reserved Students. Remote keyboard/mouse control is optional and permission-enforced.

## LinkedIn draft

I built Karizmi Exam Monitoring System to explore practical-exam monitoring without cloud infrastructure. The project integrates and customizes UltraVNC engines with native Windows interfaces, LAN discovery, authenticated pairing, encrypted communication, and per-student session management.

An earlier version worked in my functional test using three physical laptops on a LAN. This developer-reported milestone is separate from validation of the latest binaries: physical discovery/recovery retesting, broader classroom acceptance, and independent security review remain open. The project is a Development Preview.

Source and build documentation: https://github.com/AKKarizmi/Karizmi-EMS
