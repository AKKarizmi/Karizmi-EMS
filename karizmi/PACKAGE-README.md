# Karizmi EMS ? Development Preview

Windows 10/11 x64. Monitor Smarter. Examine Better. Stay Offline.

Keep all extracted files together. Run KarizmiTeacher.exe on the teacher computer or KarizmiStudent.exe on each student computer. Student requires the included vnchooks.dll. Portable launch does not install the optional service.

Both sides require an IPv4 peer-accessible LAN and Set up exam connection with UAC approval. Select Student in Teacher, enter the eight-digit Student code, and compare/confirm the phrase on both PCs. Open a tile to monitor; request control separately. Disconnect revokes pairing; closing the main window hides to tray; Exit quits. See [classroom instructions](CLASSROOM.md) and [service instructions](SERVICE.md).

Earlier developer-reported testing on three physical LAN laptops succeeded; it does not validate the latest build. Latest physical discovery/recovery acceptance and independent security review remain outstanding.
